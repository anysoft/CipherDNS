审查日期：2026-10-20。基于既有 v0.1 实现和验证记录继续开发；保留成熟密码库、96 位随机 IV、16 字节认证标签、严格 Base64 和 `CD1:` 二进制格式。以下为本轮确认的问题，不是对所有潜在缺陷的穷尽证明。

## P0

本次审查未发现已证实的 P0。系统 CSPRNG、AES-GCM Tag 验证、错误 Key 不覆盖输出、密钥文件私有权限及认证失败不执行 Hook 的路径继续通过测试。密码实现 `src/crypto.c` 未作业务修改；新增用 v0.1 库生成的固定密文兼容用例。

## P1：已修复

| 问题 | 风险与修复 | 证据 |
|---|---|---|
| 所有 Provider 错误都变成 `-1` | 认证/权限错误会被当作网络故障重复发送。新增类型化错误，永久拒绝退出，网络/5xx/429 有界退避并跨轮次保留计数 | `provider.c`、`server.c`；Provider 错误分类与 Server 拒绝只发一次的测试 |
| 已有 TXT 缺少可验证归属 | 仅凭名称唯一可能覆盖无关记录。Server 预读并用配置 Key 认证已有 TXT，再按记录 ID guarded sync；新建只允许记录仍为空，更新只允许预期 ID | `server.c`；`test_server.c`、`test_e2e.c` 的无关 TXT、其他 Key、ID guard 用例 |
| Cloudflare TXT 表示格式 | API 引号/转义会使相同逻辑内容比较失效。按 RFC1035 表示写入，读取时还原字符字符串并处理历史未加引号格式 | `provider.c`；引号、分段、转义 Mock |
| Aliyun Zone 选择及状态大小写 | 委派子域可能落入父域查询。显式传 `DomainName`，接受官方状态大小写表示 | Aliyun 官方 API 核对及 Mock 参数断言 |
| 分页快照计数变化 | 列表变化可能导致错误地认为记录不存在。三家 API 均拒绝分页中的总数变化、不完整列表和多条歧义 | 三家跨页与计数变化回归 |
| POSIX Hook 成功退出仍留子进程 | 后续更新可能与后台子进程重叠。完成或失败均清理受管进程组；服务应由独立服务管理器托管 | `platform.c`；FIFO 同步的遗留子进程回归 |
| 缓存隐藏 NUL / Resolver 超长返回 | 损坏缓存可能被当作合法前缀；Resolver 报告长度若超出缓冲区可能越界。拒绝隐藏尾部和超长长度 | `client.c`、`dns.c`；损坏/截断/超长注入用例及 Sanitizer |
| 缓存重试依赖下一次 DNS 成功 | Hook 已成功但落盘失败时，DNS 持续故障会阻止缓存重试。独立重试已应用状态持久化 | `client.c`；缓存失败后 DNS 故障恢复回归 |

## P2 与明确策略

- HTTPS 保留证书链、主机名和 SNI 验证；代理环境变量不参与直接 socket 连接。301/302/307/308 不自动跳转，也不向其他主机转发凭据。HTTP 长度、chunked、连接关闭、响应上限及所有失败释放路径继续测试。
- Server 已同步不表示 Client 已读到新 TXT；传播延迟由独立 DNS 查询决定。新增延迟传播回归，失败仍保留最后成功地址。
- 增加 `doctor` 的 schema / Key / 凭据 / 目录 / Resolver / TLS 诊断；默认不执行 Hook、IP 命令或云写入，认证读取需显式开关。
- 真实 API 工具、CI 执行、ARMv5 GCC 和硬件验收原先缺失；工具及配置已补齐，环境受限项保持 PENDING / SKIP / CI_NOT_RUN。
- Client 文件体积增加如实记录；LTO、`-Oz` 实际试验不值得改变默认代码生成。没有引入第二套 TLS 或删除证书验证。

API 列表与写入之间没有三家通用的原子 CAS。Record ID guard 不能阻止其他写入者在同一 ID 上并发修改；一个配置名称仍须独占。Provider 索引延迟、响应丢失后的云端状态和 DNS TTL 应在真实验收中单列；测试工具不会自动删除不确定归属的记录。
